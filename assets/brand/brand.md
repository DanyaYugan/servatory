# Servatory — фирменный стиль

## Идея

**Servatory** = «services» + «conservatory» (оранжерея).
Место, где сервисы содержатся, растут и за ними смотрят.

Знак: стеклянный купол оранжереи с переплётом, под ним — контейнер,
в центре янтарная дверь. Читается как «контейнер под стеклом»:
сервисы собраны в одном месте и под присмотром.

## Цвета

| Роль | HEX | Где |
|---|---|---|
| Фон | `#0E3B3E` | плитка иконки, тёмная тема |
| Знак | `#8FD8CF` | купол, переплёт, контейнер |
| Акцент | `#F0C987` | дверь, важные элементы |
| Тёмный знак | `#0E3B3E` | знак на светлом фоне (inverse) |
| Фон тёмной темы | `#0B1418` | страницы панели |

Пропорции: фон 60%, знак 35%, акцент 5%.

## Правила

```
минимальный размер знака  16 px (favicon), 32 px (интерфейс)
охранное поле             не меньше 25% ширины знака со всех сторон
на тёмном фоне            основной знак или mono
на светлом фоне           inverse или тёмный знак без подложки
надпись                   только строчными, Inter/Segoe UI, 600
```

## Чего не делать

```
не менять цвет двери на холодный
не добавлять тени, градиенты, блики
не поворачивать и не растягивать знак
не набирать надпись прописными
не ставить знак на пёстрый фон
не обводить контуром
```

## Шрифт

```
надпись   Inter (или Segoe UI как запасной), вес 600, строчные
интерфейс системный стек: Inter, Segoe UI, Roboto, sans-serif
```
