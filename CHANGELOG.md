# История версий Servatory

Формат версии: `MAJOR.MINOR.PATCH` плюс стадия (`alpha`, `beta`, `rc`).
Правила — в `docs/plan/versioning.md`.

## 0.2.0-beta — 24.10.2026

Добавлено:

- домены и TLS через панель: Caddy создаётся и управляется из настроек
- HTTPS для localhost и IP через внутренний CA, для домена — Let's Encrypt
- миграции базы: PRAGMA user_version, таблица settings, версия схемы
- доверие X-Forwarded-Proto, Secure-cookie за прокси
- руководство администратора: установка, TLS, обновление, восстановление
- образ `danyayugan/servatory:0.2.0-beta` в Docker Hub
- установка через `compose.release.yml` и `.env.release.example`
- workflow релиза собирает amd64 в Docker Hub

Известные ограничения:

- кнопка обновления самой панели
- мастер первого запуска
- установка одной командой без клонирования

## 0.2.0-alpha.4 — 23.10.2026

Добавлено:

- журнал действий: вход, выход, изменения, результат; «Настройки → Журнал»
- проверки работоспособности по HTTP: адрес, интервал, последний результат
- логи контейнера на странице сервиса, вкладка «Логи»
- фоновая проверка раз в 30 секунд

## 0.2.0-alpha.3 — 23.10.2026

Добавлено:

- раздел «Настройки → Безопасность»: своя учётная запись и смена пароля
- смена своего пароля завершает все сессии

Исправлено:

- нельзя менять роль своей учётной записи, даже superadmin
- своя учётка убрана из списка пользователей, чтобы не потерять доступ

## 0.2.0-alpha.2 — 23.10.2026

Добавлено:

- пользователи в SQLite, пароли хранятся хешем PBKDF2
- роли: superadmin, admin, operator, viewer
- права: просмотр, управление действиями, управление сервисами, пользователи
- страница «Настройки → Пользователи» для superadmin
- первый вход создаёт администратора из config.toml
- проверка прав на API: 403 при недостатке прав

## 0.2.0-alpha.1 — 23.10.2026

Добавлено:

- каркас интерфейса: верхняя панель (лого, поиск, добавление, настройки) и страницы
- обзор с поиском и группами, карточка только с «Открыть» и меню ⋯
- страница сервиса: обзор, бэкапы, настройки
- группы и хосты перенесены во вкладки настроек
- детальный эндпоинт контейнера: тома, сеть, ссылка
- SPA-маршруты в FastAPI (глубокие ссылки вида /ui/services/name)

## 0.1.0-alpha.12 — 23.10.2026

Добавлено:

- установка из docker-compose YAML (один сервис)
- автозаполнение портов, томов и переменных из README образа
- Enter в поле новой группы

Исправлено:

- кнопки карточек выходили за границы — теперь переносятся
- ограничение ссылки только http/https убрано

## 0.1.0-alpha.11 — 23.10.2026

Добавлено:

- поиск образов через Docker Hub: имя, описание, звёзды, загрузки, official
- выбор тега после выбора образа
- подсказки в поле «Образ» с задержкой 300 мс
- кеш ответов Docker Hub на 5 минут

## 0.1.0-alpha.10 — 23.10.2026

Добавлено:

- восстановление томов из копии: кнопка «Восстановить» в списке копий
- подтверждение вводом имени сервиса
- автоматическая safety-копия перед восстановлением
- остановка, распаковка, запуск и проверка состояния
- при неудачном запуске — попытка отката на safety-копию

## 0.1.0-alpha.9 — 23.10.2026

Добавлено:

- вход через форму: логин и пароль, сессия в cookie HttpOnly
- CSRF-токен для изменяющих запросов
- выход из панели, имя и роль в шапке
- срок жизни сессии в конфиге (`session_hours`, по умолчанию 12)
- Basic-авторизация убрана, `/ui/` открывается без входа

## 0.1.0-alpha.8 — 23.10.2026

Добавлено:

- бэкап томов сервиса: кнопка «Бэкап», архив tar.gz через одноразовый alpine
- список копий на карточке: дата, размер, удаление
- хранение N последних копий (по умолчанию 5), старые удаляются
- проверка архива: читается и содержит файлы
- том `servatory-backups` для архивов

## 0.1.0-alpha.7 — 23.10.2026

Добавлено:

- ссылка на карточке сервиса: «Открыть ↗» в новой вкладке
- автоматическая ссылка `http://<хост панели>:<первый публичный порт>`
- своя ссылка: кнопка «Ссылка», пустое значение возвращает автоматическую
- проверка ссылки: только http:// или https://

## 0.1.0-alpha.6 — 23.10.2026

Добавлено:

- обновление контейнера: скачивание образа, пересоздание с сохранением
  настроек, проверка запуска, откат при сбое
- сообщение «уже последняя версия», если образ не изменился
- кнопка «Обновить» на карточке и отчёт «было → стало»

## 0.1.0-alpha.5 — 23.10.2026

Добавлено:

- группы сервисов: создание, переименование, удаление
- порядок групп стрелками вверх/вниз
- назначение контейнера в группу из карточки
- разделы на главной: группы и «Без группы»
- номер версии в шапке интерфейса
- этот файл истории версий

Хранение: SQLite в каталоге данных (`/data/servatory.db`), привязка по имени
контейнера.

Исправлено:

- поле «Новая группа» не сохраняло ввод, создание падало с ошибкой 422

## 0.1.0-alpha.4 — 23.10.2026

Добавлено:

- установка контейнера из формы: имя, образ, порты, тома, переменные, политика перезапуска
- скачивание образа перед созданием
- удаление контейнера с сохранением именованных томов
- проверка имени, портов, томов и переменных

## 0.1.0-alpha.3 — 23.10.2026

Добавлено:

- действия: старт, стоп, перезапуск
- кнопки на карточке, подтверждение остановки
- сообщение об ошибке действия

Исправлено:

- стоп падал по таймауту 5 секунд: Docker ждёт до 10, таймаут действия поднят до 30

## 0.1.0-alpha.2 — 23.10.2026

Добавлено:

- провайдер Docker через локальный сокет
- список контейнеров: имя, образ, состояние, порты, метки
- главная страница с карточками и автообновлением раз в 10 секунд
- монтаж docker.sock в контейнер, группа docker через `DOCKER_GID`

Исправлено:

- порты дублировались (IPv4 и IPv6) — оставляем уникальные

## 0.1.0-alpha.1 — 23.10.2026

Добавлено:

- каркас FastAPI: `/health`, `/ready`, `/api/v1/meta`
- вход по паролю, роль `superadmin`
- отдельный `config.toml`: логин, пароль, порт, роль, Docker, UI, логи
- переменные окружения перекрывают файл настроек
- Dockerfile, compose, systemd, install.sh
- тесты и линтер, CI
- развёртывание на тестовой ВМ 104
