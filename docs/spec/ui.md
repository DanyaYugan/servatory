# Интерфейс: страницы и состояния

Фронтенд: Vue 3 + Vite + Naive UI, `vue-i18n`, `pinia`.
Отдаётся бэкендом как статика, API на том же origin.

## Общие требования

```
мобильная вёрстка от 360 px
тёмная и светлая тема, следует системной
клавиатурная навигация, фокус видим
пустые состояния с подсказкой, что делать
ошибки API показываются человеческим текстом
все тексты через i18n (ru/en), без строк в коде
```

## /wizard — первый запуск

```
1 окружение      проверка Docker, сокета, порта; кнопка «Повторить»
2 вход           managed Caddy / внешний / без TLS; домен и e-mail
3 администратор  логин, пароль, TOTP (предложить)
4 Telegram       токен и чат; кнопка «Проверить»
5 сервисы        найдено N контейнеров; подключить / пропустить
6 готово         ссылка, QR, краткая шпаргалка
```

Нельзя закрыть мастер без завершения, но можно пропустить шаги 3–5
(тогда вход по одноразовой ссылке в логах).

## /dashboard

```
карточки: всего сервисов, запущено, проблемы, обновления
лента событий (SSE)
блок «требует внимания»: упавшие, дрейф, старые бэкапы
быстрые действия: обновить всё, применить маршруты
```

## /services

```
таблица или карточки (переключатель)
колонки: имя, группа, состояние, домен, версия, обновление, бэкап
фильтры: группа, состояние, есть обновление
поиск по имени
кнопка «Добавить сервис»
```

## /services/{id}

```
шапка: имя, состояние, провайдер, домен, кнопки действий
вкладки:
  обзор      метрики, проверки, последние события
  настройки  домен, группа, иконка, политика обновлений, бэкап
  логи       tail, автообновление
  бэкапы     список, создать, восстановить
  права      гранты для пользователей
  опасное    удалить (с сохранением тома по умолчанию)
```

## /groups

```
список групп, порядок перетаскиванием, иконка, имя
```

## /updates

```
таблица: сервис, было → стало, политика, окно
кнопки: обновить выбранные, обновить всё
для пересборок отдельная метка
```

## /users и /roles

```
пользователи: логин, роли, статус, последний вход, 2FA
роли: набор разрешений чекбоксами, встроенные нельзя удалить
гранты: выбор пользователя и сервиса, разрешить/запретить
```

## /integrations

```
Провайдеры: список, добавить, проверить соединение
Caddy: режим, статус, последнее применение, кнопка «Применить»
Telegram: токен, чат, тест
```

## /audit

```
фильтры: пользователь, действие, период
таблица: время, кто, что, объект, результат
```

## /settings

```
вид: тема, язык, плотность
обновления: политика по умолчанию, окно
бэкапы: ретеншн
экспорт/импорт
версия и схема БД
```

## Состояния

```
loading    скелетоны, не спиннер на весь экран
empty      «сервисов пока нет — добавьте первый»
error      текст + код + кнопка «Повторить»
denied     «нет прав: обратитесь к администратору»
offline    баннер «нет связи с hub, переподключение…» (SSE reconnect)
```

## SSE-клиент

```
подключение к /api/v1/events
переподключение с задержкой 1→30 с, экспоненциально
при reconnect — полная перезагрузка списка
```

```
ключи: service.state.running, wizard.step1.title, ...
проверка в CI: нет «сырых» строк в компонентах
```
