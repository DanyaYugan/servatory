## Правило сервера

```
Homepage на основной ВМ остаётся основным интерфейсом
Servatory — отдельный проект на отдельной ВМ
Servatory не управляет сервисами основной ВМ, не добавляет их карточки
и ссылки, не читает её конфиги и метрики
это правило этого сервера, не ограничение продукта
```

## Найденные грабли

```
стоп контейнера длится до 10 секунд: таймаут действия должен быть больше,
иначе Docker отвечает, а клиент уже отвалился (было 5 с, стало 30 с)
Docker отдаёт порт дважды (IPv4 и IPv6) — дубликаты убираем при разборе
```

## Риски

```
docker.sock в контейнере = root на хосте; для тестовой ВМ допустимо,
перед выходом за её пределы нужен socket-proxy или ограничение прав
пароль в config.toml хранится открытым текстом; позже хеш
```
