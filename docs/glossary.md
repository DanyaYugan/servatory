# Словарь терминов

Термины продукта и английские имена для кода. Дальше используем их без
расхождений.

## Компоненты

| Термин | English | Значение |
|---|---|---|
| **Hub** | `hub` | Продукт целиком: один процесс core + web + bot |
| **Ядро** | `core` | Состояние, реестр, провайдеры, действия, API, права |
| **Веб** | `web` | SPA-интерфейс, отдаётся ядром |
| **Бот** | `bot` | Telegram-клиент ядра |
| **Джобы** | `jobs` | Отдельный процесс: расписание, алерты, поиск обновлений |
| **Агент** | `agent` | Демон на удалённом хосте (1.1) |
| **Вход** | `ingress` | Caddy и режимы его управления |

## Данные

| Термин | English | Значение |
|---|---|---|
| **Реестр** | `registry` | Сервисы, группы, настройки в базе |
| **Метка** | `label` | Самоописание контейнера (`hub.*`) |
| **Карточка** | `card` | Представление сервиса в интерфейсе |
| **Проверка** | `check` | Правило доступности: http, tcp, container |
| **Политика** | `policy` | Обновления, бэкап, окна обслуживания |
| **Секрет** | `secret` | Значение, хранимое шифрованным |
| **Журнал** | `audit` | Кто, что, когда, результат |
| **Операция** | `operation` | Длительное действие с идентификатором |

## Состояние и действия

| Термин | English | Значение |
|---|---|---|
| **Желаемое** | `desired` | Что описано в реестре |
| **Фактическое** | `actual` | Что реально в Docker |
| **Дрейф** | `drift` | Расхождение между ними |
| **Сверка** | `reconcile` | Приведение факта к желаемому |
| **Применить** | `apply` | Сгенерировать конфиги и применить изменения |
| **Идемпотентность** | `idempotent` | Повтор не создаёт дублей |
| **Событие** | `event` | Уведомление клиентам через SSE |

## Права

| Термин | English | Значение |
|---|---|---|
| **Роль** | `role` | Набор разрешений: admin, operator, viewer, custom |
| **Разрешение** | `permission` | `service.read`, `service.action.update`, ... |
| **Грант** | `grant` | Точечное разрешение на один сервис |
| **Сессия** | `session` | Вход в веб через cookie |
| **Токен** | `token` | Доступ API/бота через Bearer |

## Вход

| Термин | English | Значение |
|---|---|---|
| **Режим входа** | `tls_mode` | managed, external, labels, none |
| **Маршрут** | `route` | Домен → сервис |
| **Последний рабочий конфиг** | `last_good` | Конфиг Caddy для отката |

## Чего не путать

```
hub ≠ страница        hub — процесс, страница — его часть
метка ≠ реестр        метка объявляет, реестр хранит окончательное
карточка ≠ сервис     карточка исчезает с сервисом, но не наоборот
apply ≠ reconcile     apply — команда человека, reconcile — автоматика
том ≠ каталог         том Docker или /data/services/<name>
роль ≠ грант          роль широкая, грант — исключение на сервис
```
