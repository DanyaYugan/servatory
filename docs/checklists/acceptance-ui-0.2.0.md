# Проверка нового интерфейса 0.2.0

Ориентир: 30–40 минут.

```
URL:    http://<host>:8090/ui/
Логин:  admin
Пароль: admin
```

## A. Вход и каркас

- [ ] A1. Открывается форма входа, а не запрос пароля браузера
- [ ] A2. Сверху шапка: логотип, поиск, «Добавление», «Настройки»
- [ ] A3. Сайдбара нет; логин, роль, версия и «Выйти» — в «Настройках»
- [ ] A4. «Выйти» возвращает форму входа

## B. Обзор

- [ ] B1. Видны карточки `servatory` и `uptime-kuma`
- [ ] B2. На карточке только «Открыть ↗» и «⋯»
- [ ] B3. Поиск по имени фильтрует карточки
- [ ] B4. «Открыть ↗» открывает сервис в новой вкладке
- [ ] B5. Клик по карточке открывает страницу сервиса
- [ ] B6. Меню «⋯» открывается и не закрывает страницу

## C. Страница сервиса

- [ ] C1. Адрес вида `/ui/services/servatory`
- [ ] C2. Вкладки: Обзор, Бэкапы, Настройки
- [ ] C3. На «Обзоре» видны состояние, образ, порты, сеть, тома, группа, ссылка
- [ ] C4. «← Назад к обзору» возвращает на главную
- [ ] C5. Перезагрузка страницы (F5) остаётся на сервисе
- [ ] C6. Кнопки «Стоп», «Перезапуск», «Обновить» работают
- [ ] C7. Вкладка «Бэкапы» показывает копии Кумы, если открыть её страницу
- [ ] C8. Вкладка «Настройки» позволяет сменить группу и ссылку

## D. Установка

- [ ] D1. Раздел «Установить» открывается отдельной страницей
- [ ] D2. Есть переключатель «Форма» / «YAML»
- [ ] D3. В поле «Образ» поиск выдаёт подсказки
- [ ] D4. Выбор `elestio/uptime-kuma` подставляет порт и том
- [ ] D5. После установки открывается страница нового сервиса
- [ ] D6. После удаления возвращает на обзор (или ошибка, если сервис занят)

## E. Группы

- [ ] E1. «Настройки» → вкладка «Группы» открывается
- [ ] E2. Пока групп нет — надпись «Групп пока нет»
- [ ] E3. Создание группы по Enter работает
- [ ] E4. Переименование и удаление работают
- [ ] E5. Порядок меняется стрелками
- [ ] E6. На странице сервиса группа выбирается из списка

## F. Хосты и настройки

- [ ] F1. «Настройки» → вкладка «Хосты» показывает локальный сервер и число сервисов
- [ ] F2. Вкладка «Общие» показывает версию, схему, пользователя, пути
- [ ] F3. Кнопка «Выйти» находится во вкладке «Общие»

## G. Глубокие ссылки

- [ ] G1. Открыть `/ui/services/uptime-kuma` напрямую — страница открылась
- [ ] G2. Открыть `/ui/settings` напрямую — страница открылась
- [ ] G3. Обновление F5 на любой странице не даёт 404

## H. Регрессия API

- [ ] H1. `GET /api/v1/containers` без входа → 401
- [ ] H2. Вход и `GET /api/v1/containers` → 200
- [ ] H3. `GET /api/v1/containers/servatory` → тома и сеть
- [ ] H4. Создание копии Кумы и восстановление по-прежнему работают
